# Racks Madurai – Business Website

A professional business website built for **Racks Madurai**, a supermarket and storage rack manufacturing unit based in Trichy, Tamil Nadu, serving customers across Tamil Nadu.

This project focuses on building a clean, modern, and lead-generating online presence for a manufacturing business.

---

## 📌 Project Overview

**Business Type:** Manufacturing / Retail Infrastructure  
**Location:** Trichy, Tamil Nadu  
**Service Area:** Tamil Nadu  

The goal of this project was to redesign an outdated website and create a professional, mobile-friendly platform that helps customers easily view products and contact the business.

---

## 🚀 Key Features

- Modern, professional UI design
- Fully mobile-responsive layout
- Product showcase with categories
- WhatsApp enquiry integration
- Call-to-action buttons for leads
- SEO-ready structure (titles, meta, headings)
- Optimized images for fast loading
- Google Maps location integration

---

## 🛠️ Tech Stack

- HTML5
- CSS3 / Tailwind CSS
- JavaScript
- Static website (SEO-friendly)

---

## 🎯 Business Impact

- Improved brand credibility
- Easier customer enquiries via WhatsApp
- Professional online presence suitable for manufacturers and local businesses
- Built as a scalable foundation for future SEO growth
